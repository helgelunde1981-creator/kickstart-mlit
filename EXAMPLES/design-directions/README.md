# Design directions — tokens og font-pairings

Én mappe per retning fra `docs/standards/02-DESIGN_DIRECTIONS.md`. Hver mappe
har foreløpig `tokens.css` (komplette CSS custom properties, klare til å limes
inn i et prosjekt) og `font-pairings.md` (anbefalte pairings, alle på Google
Fonts). Screenshots, referanser og eksempelkomponenter (hero/card/nav) fylles
på etter hvert som vi bygger prosjekter i retningen.

Disse filene leses IKKE av genereringen på runtime (kun `docs/standards/*.md`
sendes til modellen) — de er fasit for oss når vi bygger, og råstoff når
standarddokumentet skal utdypes.
